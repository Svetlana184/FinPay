# AndroidKursach

## План курсовой
- спроектировать систему
- бдшка
- экраны

### База данных 
Пользователи:
- айди
- пароль
- логин
- телефон/почта
- отпечаток пальца
- согласие с условиями
- имя (ФИО)
- face id

Карточки:
- айди
- номер
- айди аккаунта

Аккаунты:

Переводы:
- айди карточки
- айди получателя
- имя
- номер карты
- количество денег
- валюта
- комментарий
- сохранение
- комиссия
- otp (?)
- банк
- ветка банка

Сообщения:
- время отправки
- текст
- получатель

Счета

Настройки:
- язык
- информация о приложении (дата создания, версия)

### Функционал
- вход (вход, регистрация, восстановление пароля, вход по отпечатку пальца)
- изменение настроек (язык, изменение пароля, изменение данных о себе и отпечатка пальца)
- аккаунты (просмотр)
- карточки
- смски пользователю
- перевод денег
- обмен валюты
