# **FINPAY** — **приложение управления финансами**

### **Приложение относится к сфере финансовых технологий и представляет собой мобильный банкинг с элементами управления личными финансами и платёжными сервисами.**

Область применения охватывает:
1.	Розничный цифровой банкинг — повседневные операции частных лиц: переводы, оплата счетов, контроль счетов и карт.
2.	Валютно-финансовые сервисы — отображение актуальных курсов ва-лют.
3.	Геолокационные финансовые сервисы — поиск ближайших банкоматов и обменных пунктов на карте.
4.	Управление личными финансами — статистика расходов/доходов и исто-рия операций.
5.	Управление банковскими продуктами — картами и аккаунтами пользова-теля.
